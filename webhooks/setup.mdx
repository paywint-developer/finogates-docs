Before you can receive webhooks, you must register your endpoint URL in your Finogates dashboard.

---

## Sandbox Environment

Use the **Sandbox environment** to test webhook delivery before you go live.

1. **Create a Sandbox Account**  
   Sign up at **app.finogates.com**.

2. **Get Your API Credentials**  
   Go to **Settings → API Credentials** to get your Sandbox `client_id` and `client_secret`.  
   [Open Sandbox Settings → API Credentials](https://app.finogates.com/developer-panel)

3. **Add Your Webhook URL**  
   Go to **Settings → Redirect/Webhook** and add your webhook endpoint.  
   Example:
   ```text
   https://example.com/webhook
   ```

4. **Test Webhook Delivery**  
   Use test events to check that your endpoint receives them correctly.

---

## Production Environment

Once your tests pass in Sandbox, repeat these steps in the **Production environment**.

1. **Create a Production Account**  
   Go to **app.finogates.com**.

2. **Request Production Access**  
   Complete onboarding in the [Dashboard](https://app.finogates.com/dashboard). Then wait for our team to review and approve your production access.

3. **Get Your Production API Credentials**  
   In **Settings → API Credentials**, copy your production `client_id` and `client_secret`.  
   [Open Production Settings → API Credentials](https://app.finogates.com/developer-panel)

4. **Add Your Webhook URL**  
   Add your production webhook endpoint in **Settings → Redirect/Webhook**.  
   Example:

   ```text
   https://yourapp.com/webhook
   ```

5. **Support Contacts**

   * **Email:** [support@finogates.com](mailto:support@finogates.com)

---

## Best Practices

* Use **HTTPS** for all webhook endpoints.
* Return **`200 OK` quickly**. Do any heavy work after you respond.
* Log event **IDs** and timestamps. They help you spot repeated events and keep an audit trail.
* You must store your **webhook signing secret** securely.
