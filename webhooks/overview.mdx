A webhook is a message we send to your server when an event happens. This means you don't have to poll the API. For example, we can tell you when:

- A payment succeeds
- A bank account is added
- A user's identity check (KYC) is approved

## How It Works

1. You register an HTTPS endpoint and choose which events it receives.
2. When an event happens, we send it to your endpoint as a JSON `POST`.
3. Your endpoint verifies the signature and responds with a `2xx` status.
4. If a delivery fails, we retry it.
