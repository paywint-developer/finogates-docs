Each family page lists its events, an example payload and the data fields.

| Family                                        | Events                                                                                                                                                                                                                                                                                                                        |
|-----------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [Payment](/webhooks/events/payment)           | `payment_intent.created`, `payment_intent.validated`, `payment_intent.approved`, `payment_intent.rejected`, `payment_intent.executing`, `payment_intent.succeeded`, `payment_intent.settled`, `payment_intent.failed`, `payment_intent.voided`, `payment_intent.refunded`, `payment_intent.charged_back`, `payment_intent.document_scanned` |
| [KYC](/webhooks/events/kyc)                   | `user_kyc.applied`, `user_kyc.in_review`, `user_kyc.approved`, `user_kyc.semi_approved`, `user_kyc.rejected`, `user_kyc.reopened`, `user_kyc.required`, `user_kyc.deleted`                                                                                                                                                      |
| [KYB](/webhooks/events/kyb)                   | `user_kyb.applied`, `user_kyb.approved`, `user_kyb.rejected`, `user_kyb.reopened`, `user_kyb.deleted`                                                                                                                                                                                                                            |
| [Card](/webhooks/events/card)                 | `payment_method.card.added`, `payment_method.card.add_failed`, `payment_method.card.review_pending`, `payment_method.card.review_approved`, `payment_method.card.review_rejected`, `payment_method.card.image_requested`, `payment_method.card.deleted`                                                                          |
| [Bank Account](/webhooks/events/bank)         | `payment_method.bank.added`, `payment_method.bank.add_failed`, `payment_method.bank.relink_required`, `payment_method.bank.relinked`                                                                                                                                                                                            |

Every event uses the envelope described in [Events](/webhooks/events).
