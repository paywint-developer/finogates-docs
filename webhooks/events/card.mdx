## Events

| Event                                   | Sent when                                         | Additional fields                                  |
|-----------------------------------------|---------------------------------------------------|----------------------------------------------------|
| `payment_method.card.added`             | A card is added.                                  | `card`, `status`, `requires_manual_review`         |
| `payment_method.card.add_failed`        | A card could not be added.                        | `failure_reason`, `failure_message`                |
| `payment_method.card.review_pending`    | A card is held for manual review.                 | `card`, `status` (`under_review`)                  |
| `payment_method.card.review_approved`   | The review approved the card.                     | `status` (`approved`), `reason`                    |
| `payment_method.card.review_rejected`   | The review rejected the card.                     | `status` (`rejected`), `reason`                    |
| `payment_method.card.image_requested`   | The user must upload card images.                 | `card_id`, `card`, `note`, `verification_state`    |
| `payment_method.card.deleted`           | A card is removed.                                | `card`, `status` (`disabled`)                      |

## Data Fields

<ResponseField name="payment_method_id" type="string">
  The card's id. `image_requested` sends it as `card_id`.
</ResponseField>

<ResponseField name="user_id" type="string">
  The user the card belongs to.
</ResponseField>

<ResponseField name="card" type="object">
  Card details. Always `last4` and `brand`; `card.added` also sends expiry, cardholder name and nickname.
</ResponseField>

<ResponseField name="status" type="string">
  The card's status, e.g. `active` or `pending`.
</ResponseField>

<ResponseField name="requires_manual_review" type="boolean">
  On `card.added`, `true` when the card is held for review; `review_reason` says why.
</ResponseField>

<ResponseField name="platform_id" type="string">
  Your platform id. `tenant_id` has the same value.
</ResponseField>
