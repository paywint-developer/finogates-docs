## Events

| Event                                  | Sent when                                                                 | Additional fields                    |
|----------------------------------------|---------------------------------------------------------------------------|--------------------------------------|
| `payment_method.bank.added`            | A bank account is added, or a manually added one is connected instantly.  | `bank`, `status` (`active`)          |
| `payment_method.bank.add_failed`       | The hosted add-bank page finished without adding a bank account.          | `failure_reason`, `failure_message`  |
| `payment_method.bank.relink_required`  | The user must sign in to their bank again.                                | `status`, `reason`                   |
| `payment_method.bank.relinked`         | The user reconnected the bank.                                            | `status` (`relinked`)                |

We send `payment_method.bank.added` for banks added with [Add account Instantly](/api-reference/bank-accounts/add-account-instantly) and [Add a Bank Account From an Existing Connection](/api-reference/bank-accounts/add-account-from-connection). A manually added bank that is later connected instantly keeps its `payment_method_id`, and we send the event again.

After `relink_required`, payments from the bank fail with `bank_relink_required`. This continues until the user reconnects using [Get Bank Account Relink Link](/api-reference/bank-accounts/get-bank-account-relink-link). A bank added from an existing connection is reconnected in your app instead.

## Data Fields

<ResponseField name="payment_method_id" type="string">
  The bank account's ID. `null` on `add_failed`.
</ResponseField>

<ResponseField name="user_id" type="string">
  The user the bank account belongs to.
</ResponseField>

<ResponseField name="bank" type="object">
  Masked details: `account_mask`, `routing_last4`, `account_type`, `account_holder_name`, `bank_name`. We never send full numbers.
</ResponseField>

<ResponseField name="failure_reason" type="string">
  On `add_failed`. For example, `bank_already_added`.
</ResponseField>

<ResponseField name="reason" type="string">
  On `relink_required`, this is always `bank_relink_required`.
</ResponseField>

<ResponseField name="platform_id" type="string">
  Your platform ID. `tenant_id` has the same value.
</ResponseField>
