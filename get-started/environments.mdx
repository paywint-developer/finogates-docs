## Sandbox
1. Sign up for an account at [app.finogates.com/signup](https://app.finogates.com/signup).
2. You get access to your sandbox account right away.
3. Go to the [Developer Panel](https://app.finogates.com/developer-panel) to get your `client_id` and `client_secret`. You use them to access all sandbox APIs. See [Authentication](/get-started/authentication).
4. Set the API base URL to: `https://sandbox-api.finogates.com`

## Production
After you sign up and get sandbox access, complete onboarding to request production access.

1. Complete onboarding in the [Dashboard](https://app.finogates.com/dashboard).
2. Wait for our team to review and approve your production access.
3. Go to the [Developer Panel](https://app.finogates.com/developer-panel) to get your production `client_id` and `client_secret`.
4. Set the API base URL to: `https://api.finogates.com`
