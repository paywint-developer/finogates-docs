## Sandbox
1. Register for an account at [app.finogates.com/signup](https://app.finogates.com/signup).
2. You’ll instantly get access to your sandbox account.
3. Navigate to the [Developer Panel](https://app.finogates.com/developer-panel) to obtain your API key for accessing all sandbox APIs.
4. Set the API base URL to: `https://sandbox-api.finogates.com`

## Production
After registering and getting sandbox access, complete onboarding to request production access.

1. Complete onboarding in the [Dashboard](https://app.finogates.com/dashboard).
2. Wait for our team to review and approve your production access.
3. Navigate to the [Developer Panel](https://app.finogates.com/developer-panel) to obtain your production API key.
4. Set the API base URL to: `https://api.finogates.com`
