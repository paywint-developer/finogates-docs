Use the Finogates APIs to add full payment features to your app. These cover:

- Creating and verifying users
- Adding money to wallets
- Transfers
- Payouts

Make your first API calls in the **Sandbox environment**.

## Follow Events in Real Time

A webhook is a message we send to your server when something happens. We send webhooks for important events, such as:

* `user_kyc.approved`
* `payment_method.bank.added`
* `payment_intent.succeeded`
* `payment_intent.failed`

To learn how to verify webhook signatures and handle retries, see the [Webhooks Overview](/webhooks/overview).
