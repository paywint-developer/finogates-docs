## Allowed Protocols

We only support secure **HTTPS** URLs.

Blocked schemes include:

- `http://`
- `file://`
- `ftp://`
- `javascript://`
- `data://`

---

## Network Restrictions

URLs cannot resolve to:

- Private IP ranges (such as `192.168.x.x`, `10.x.x.x`)
- `localhost` or `127.0.0.1`
- Internal company servers
- Non-public networks
- Administrative service ports

We must be able to access the file over the public internet.

---

## Why These Restrictions Exist

These rules prevent:

- Exposure of internal systems  
- Security weaknesses  
- Attempts to get around public hosting  
- API failures caused by resources we can't access
