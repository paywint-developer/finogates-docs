## Overview

This page shows URLs that **meet** our requirements, and URLs we **reject** during validation. Use these examples as a reference when you create or check document URLs.

---

## Valid URL Examples

These URLs use HTTPS and point directly to downloadable files. They meet all security and accessibility requirements:

[https://cdn.example.com/docs/business-license.pdf](https://cdn.example.com/docs/business-license.pdf)  
[https://secure-storage.mycompany.com/uploads/id-proof.png](https://secure-storage.mycompany.com/uploads/id-proof.png)  
[https://drive.google.com/uc?export=download&id=1ABC123xyz](https://drive.google.com/uc?export=download&id=1ABC123xyz)  
[https://bucket-name.s3.us-west-1.amazonaws.com/registration-document.jpg](https://bucket-name.s3.us-west-1.amazonaws.com/registration-document.jpg)  
[https://assets.examplecdn.com/files/proof-of-address.jpeg](https://assets.examplecdn.com/files/proof-of-address.jpeg)

## Invalid URL Examples

These URLs fail validation because of security issues, unsupported formats, private networks or links that aren't direct:


[http://example.com/document.pdf](http://example.com/document.pdf)                     (not HTTPS)  
[https://192.168.1.10/file.pdf](https://192.168.1.10/file.pdf)                       (private IP address)  
[https://localhost:5000/file.pdf](https://localhost:5000/file.pdf)                      (localhost)  
[ftp://files.example.com/document.pdf](ftp://files.example.com/document.pdf)                (unsupported protocol)
[https://drive.google.com/file/d/12345/view](https://drive.google.com/file/d/12345/view)           (preview link, not direct download)  
[https://example.com/files/large-document-12mb.pdf](https://example.com/files/large-document-12mb.pdf)    (exceeds 7 MB size limit)  
[https://myapp.internal.company/documents/id.pdf](https://myapp.internal.company/documents/id.pdf)      (internal network resource)

## Quick Tips

- Always test URLs in an **incognito browser**. If a URL needs a login, it will fail validation.  
- Avoid preview and share pages from cloud storage.  
- A direct link doesn't need a file extension. The server must send a supported `Content-Type`, or the URL must end with a supported extension (such as `.pdf`, `.jpg`, `.png`).  
- Make sure the file is publicly reachable over HTTPS.
