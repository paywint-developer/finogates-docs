## Common Issues & Fixes

<AccordionGroup>

<Accordion title="URL uses blocked scheme">
**Problem:** The URL doesn't use HTTPS.  
**Fix:** Change `http://` to `https://`.  
</Accordion>

<Accordion title="URL resolves to private IP">
**Problem:** The URL points to an internal network.  
**Fix:** Use a public hosting provider or cloud storage.  
</Accordion>

<Accordion title="File exceeds maximum size">
**Problem:** The file is too large. The limit is 7 MB, or 10 MB for user documents.  
**Fix:** Compress it, or export it again as an optimized PDF.  
</Accordion>

<Accordion title="Unsupported file type">
**Problem:** The file extension isn't supported.  
**Fix:** Convert it to PDF, JPG or PNG.  
</Accordion>

<Accordion title="Network timeout">
**Problem:** The server doesn't deliver the file within 20 seconds.  
**Fix:** Use faster hosting or a CDN.  
</Accordion>

</AccordionGroup>
