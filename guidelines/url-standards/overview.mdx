## Overview

Some Finogates API endpoints need direct URLs to documents. Examples are KYB verification, document submission and compliance checks.

These URLs must follow certain standards. This makes sure they are secure, accessible and valid for automated processing.

This section lists all the requirements for document URLs. It covers security rules, file rules, storage tips and troubleshooting.

## Why URL Standards Matter

We check each document URL to make sure:

- The file is safe and accessible
- The host is publicly reachable
- The URL resolves correctly
- The content meets the size and type requirements

Following these rules prevents verification delays and keeps document processing smooth.

---

## When You Need These Guidelines

These URL rules apply whenever you submit a document through Finogates, including:

- KYB verification
- Uploading compliance documents
- Business identity verification
- Proof-of-address checks
- Any endpoint that accepts a document URL

For requirements specific to an API, see the documentation for that endpoint.
