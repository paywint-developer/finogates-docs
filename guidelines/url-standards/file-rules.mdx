## Requirements

### File Size
Maximum file size: **7 MB**. User documents added from a link can be up to **10 MB**.

### Download Timeout
Every file must finish downloading within **20 seconds**.

---

## Supported File Types

Supported formats depend on the API. They include:

### Documents
- PDF  

### Images
- JPG / JPEG  
- PNG  

<Note>
Always check the documentation for the API to confirm which formats it supports.
</Note>

---

## Validation Process

When you submit a URL, we run these checks:

1. **Syntax and length check**  
2. **Security rule checks**  
3. **DNS resolution**  
4. **Public IP check**  
5. **File download test**  
6. **Content type and size check**

We accept a URL only if all checks pass.
