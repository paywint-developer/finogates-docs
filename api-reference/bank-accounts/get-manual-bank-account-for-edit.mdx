---
title: "Get a Manual Bank Account's Details to Edit"
description: "Get a manually added bank account's current details to show in an edit form."
openapi: 'GET /v1/platform/bank/update/{bank_account_id}'
---

Use this for a bank account that was added with its routing and account number. Correct the details with `PATCH /platform/bank/update/{bank_account_id}`. See [Edit a Manually Added Bank Account](/api-reference/bank-accounts/edit-manual-bank-account).

The account number comes back in full, because these are the numbers you entered. We decrypt it only for this request. Never log or cache it.

A Canadian or UK bank comes back in the same shape as its add request:

- `bank_country`
- Both addresses
- Its local codes: `transit_number` and `institution_number`, or `sort_code`
- The IBAN and roll number in full

## Errors

| Code | What it means |
| --- | --- |
| `bank_not_editable` | The edit itself would refuse this bank. It was verified instantly, was removed, or was not added with its numbers. |
