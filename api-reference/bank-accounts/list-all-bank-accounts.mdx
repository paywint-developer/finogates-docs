---
title: 'List All Bank Accounts'
description: "Get every bank account on file across all of your users in a single list."
openapi: 'GET /v1/platform/bank-accounts'
---

This has the same shape as `GET /platform/bank-accounts/{user_id}`, but it is not limited to one user. See [List Bank Accounts](/api-reference/bank-accounts/list-bank-accounts).

It combines linked bank accounts and virtual bank accounts issued by us. The `type` field tells you which kind each one is. Items include the full account and routing numbers. Each item has a `user_id` that tells you whose account it is.

Use this for an overview of all your accounts. Use the per-user call when you already know the user.

The list is newest first. It is split into pages with `limit` and `offset`.
