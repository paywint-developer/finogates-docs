---
title: 'Remove an Additional Redirect URL'
description: "Remove one additional URL from a purpose."
openapi: 'DELETE /v1/platform/redirect-urls/{purpose}/additional-urls/{url_id}'
---

Card sessions can no longer be framed on this URL's origin, or return to it. The exception is when another URL of the purpose shares that origin.

To remove the primary URL, use `DELETE /v1/platform/redirect-urls/{purpose}`.
