---
title: 'Update User KYC Record'
description: "Change the address, phone or personal documents on a user's identity check (KYC)."
openapi: 'PATCH /v1/platform/users/kyc-records/{user_id}/{kyc_id}'
---

You can change the address, the phone, and the person's own documents:

- `proof_of_address`
- `identity_document`: a passport
- `photo_id`: an ID card, with `side`

The name, date of birth and SSN stay as the identity check verified them.

## Documents

Each document is either:

- **A new file:** send `url`, or `file` naming a part of a `multipart/form-data` request. The `payload` part of that request is this JSON.
- **A document we already hold, which you give a type:** send `document_id`.

## What happens to your change

| KYC status | What happens |
| --- | --- |
| Not approved yet | We save the change at once (`applied: true`). |
| Approved | The change waits for our review (`applied: false`, `pending_update`). It reaches the KYC only once it is approved, and the KYC stays approved meanwhile. You get `user_kyc.update_approved` / `user_kyc.update_rejected` once every item is decided. |
| Rejected | The call returns `409`. |
