---
title: 'Add a User''s Document From a Link'
description: "Add one typed document that we fetch once from an https link."
openapi: 'POST /v1/platform/users/{user_id}/documents/from-url'
---

The file must be a PNG, JPEG or PDF, and at most 10 MB. The same rules apply as for [Upload a User's Document](/api-reference/users/upload-user-document).
