---
title: 'List pending applications'
description: "Get your platform's applications that are still being reviewed, split into pages."
openapi: 'GET /v1/platform/pending-applications'
---

An example is a request to turn on a new product or service.

By default, the list shows only applications that are not finished yet: `pending`, `under_review` and `requires_changes`.

You can view applications here, but you can't change them. Our review team approves or rejects them.
